description: >
  My first personal web development project, built in Ruby/Sinatra using
  the Spotify API. AnyQueue lets Spotify Premium users create shareable
  rooms where guests can add songs to the host's queue via a custom search
  menu, with all user-added songs visible on the main page. Originally
  prototyped as a smaller C# version that only let people add to my own
  queue, I rebuilt it in Ruby for full-stack database management once I saw
  room to expand it. All the styling is hand-written CSS with no Bootstrap
  or Tailwind — I hadn't touched a CSS framework yet at this point. Hosted
  on AWS, currently in Spotify Development mode for beta testers.
