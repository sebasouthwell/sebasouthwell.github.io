  A group project for COM3523 — my own individual contribution was a
  Python tool that walks the real commit history of the
  <a href="https://github.com/bottlepy/bottle" target="_blank" rel="noopener">bottle</a>
  web framework — checking out every historical commit that touched its
  main source file, and at each one running static analysis: a UML class
  diagram via pyreverse and Graphviz (shown here), a call graph, and a
  lines-of-code count exported to CSV. Stitching every commit's diagram
  together produces a short animation of the codebase's structure evolving
  commit-by-commit across its real development history — a practical look
  at coupling, cohesion and how a real open-source project's architecture
  grew over time, tying directly into the module's coverage of the SOLID
  principles, refactoring and legacy-system reengineering patterns (73%).
